## 6. Traps that cost real time — take them free

- **`node -e` flips the UMD branch.** Modules take `module.exports` instead of the `ESS`
  global, so probes silently see nothing. **Test from real files only.** This bit me again
  tonight after I documented it.
- **`node --test tests/*.test.js`** — a bare `tests/` path is rejected by node 22.
- **`ESS.MODEL_ID` is provenance. Never assert equality on it.** It changes whenever any src
  module changes. Fixtures record it; tests assert the **digest**.
- **`c.step(dt)` draws a fixed number of seeded samples regardless of `dt`** — a trajectory
  depends on the NUMBER of step calls, not simulated time. A replay reconstructing time with
  a different `dt` **will** diverge.
- **`BIASED_MEASUREMENT` draws from `opts.rand`** when given no explicit magnitude. Always pass
  one; handing it the live generator shifts every subsequent noise sample and moves every golden.
- **`dist/` is a seed artifact** — `build-dist.py` reads the existing dist for the React blobs.
  Deleting it makes the build unrecoverable from this repo alone.
- **v2 snapshots carry NO `schemaVersion` at all.** Migrate on absence. A value test is
  *actively wrong*: `undefined < 3` is FALSE, so it treats a v2 record as CURRENT and skips
  migration silently. (Seat 2/3's inversion guard.)
- **Two record shapes.** `dispatch()` JOURNALS legacy `{t,op,tag,arg}` but RETURNS an
  `ActionEvent`. `drill-arch matchAction` consumes the RETURNED shape. **Feeding the scorer the
  journal scores ZERO with no error.**
- **8 legacy drills, not 12** (D1–D4, D6, D9, D11, D12). "D1–D12" is an id range.
- **3 of the 12 legacy upsets are ARCHITECTURE-class** (xmtr, drift, stick). The other nine —
  including `air` — are PROCESS. `models.js:252` settles `air`: on air loss a valve goes to
  its **designed fail-safe**; nothing in the architecture is broken.

## 7. Standing practices, earned the hard way

- **Stage by path, never `git add -A`.** It broke this branch three times: S2 swept into a docs
  commit, a dist built over a dirty tree embedding a module the commit lacked, and two commit
  messages misdescribing their contents.
- **Verify the SHA in a scratch clone, never the working tree.**
  `git clone -q --no-hardlinks . <dir> && git -C <dir> checkout -q --detach <sha>`.
  Not `git archive` — no `.git`, so repo-aware tests fail spuriously.
- **A zero is not evidence unless you have proven the instrument can produce a nonzero.**
  A verifier's sweep read 0 for `PIN_COMPARE` and would have passed it as "gated" when it had
  simply never fired it (that command needs 2–3 pins accumulated before it dispatches).
- **Positive control first.** "X does not leak" passes trivially on a broken detector.
- **A ruling that matters belongs in a test, written by someone other than the ruler** — and
  when a ruling is *reversed*, the reversal must chase every artefact encoding it.

## 8. Rulings of record (supersede anything earlier)

1. **Safety gate is OUTCOME-BASED.** A refused attempt does NOT trip it. `drill-arch matchAction`
   is correct for both families and must **not** be modified; the debrief note is additive new
   code. (Pinned by `tests/refusal-scoring.test.js`.)
2. **All five scoring commands are mode-gated at DISPATCH, failing closed** —
   MARK_EVIDENCE / PIN_COMPARE / SUBMIT_HYPOTHESIS / VERIFY diagnose-only, DEBRIEF debrief-only.
   Enforcement is at dispatch because **the scorer reads the journal, not the DOM**. Derive the
   list from `drill-arch expectedActions`, never type it.
3. **Learn is unavailable during an active A-drill.** V3-PLAN line 186: *"Learn shows the
   answer"*. Hidden, not disabled.
4. **`air` is PROCESS-class.** Split is 3/9, not 4/8.
5. **Gate 3 is split**: a REFUSED replay does not fail it — refusing is the gate *working*.

is invisible to them *by construction*. The leakage test proves a fault's identity is not
disclosed, not that its location is honest. **The defect lives in the gap.** That is the
argument for a third lens rather than a bigger version of either.
